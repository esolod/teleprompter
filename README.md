# Teleprompter (voice auto-scroll)

Простий Android-телесуфлер: поки ви говорите — текст прокручується автоскролом
з заданою швидкістю; замовкли — прокрутка зупиняється. Керування голосом
реалізоване локально через VAD (voice activity detection, аналіз RMS-амплітуди
мікрофону), без інтернету і без хмарного розпізнавання мови.

## Функціонал

- Редактор тексту промови на головному екрані.
- Слайдери: розмір шрифту, швидкість прокрутки, чутливість до голосу.
- Кнопка калібрування — 2 секунди тиші, поріг спрацювання підбирається автоматично.
- Повноекранний режим телесуфлера, лендскейп, дзеркальне відображення (для
  скла-теплеспрінтера) вмикається перемикачем.
- Ручна пауза (тап по екрану або кнопка) — перекриває голосовий тригер.
- Індикатор статусу: "слухаю" / "говорите — скрол" / "тиша — пауза" / "ручна пауза".

## Як зібрати APK (без Android Studio, через GitHub Actions)

1. Створіть новий порожній репозиторій на GitHub (public або private).
2. Запуште вміст цієї папки в його `main`:
   ```bash
   cd teleprompter
   git init
   git add .
   git commit -m "Teleprompter voice-scroll app"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git push -u origin main
   ```
3. Відкрийте вкладку **Actions** в репозиторії — workflow `Build APK` запуститься
   автоматично при push (або запустіть вручну кнопкою "Run workflow").
4. Збірка триває 3-5 хвилин. Після завершення відкрийте завершений run →
   розділ **Artifacts** внизу сторінки → завантажте `teleprompter-debug-apk.zip`.
5. Розпакуйте, всередині буде `app-debug.apk` — це і є готовий встановлюваний файл.

## Встановлення APK на телефон

1. Скиньте `app-debug.apk` на телефон (через кабель, хмару, Telegram собі і т.д.).
2. Відкрийте файл на телефоні → дозвольте встановлення з невідомих джерел, якщо
   попросить → Install.
3. При першому запуску телесуфлера додаток запитає дозвіл на мікрофон — дозвольте.

Це debug-збірка — підписана дебаг-ключем, встановлюється без Google Play,
працює без обмежень для особистого використання.

## Як зібрати локально (якщо є Android Studio)

Відкрийте папку `teleprompter` як проект в Android Studio (File → Open),
дочекайтеся Gradle Sync (підтягне залежності з вашого інтернету), потім
Build → Build Bundle(s)/APK(s) → Build APK(s).

## Налаштування чутливості вручну

Якщо автокалібрування спрацьовує не ідеально (шумне приміщення / вентилятор
ноутбука тощо), рухайте слайдер "Чутливість до голосу" на головному екрані:
- вище значення → детектор реагує на тихіший голос (але й на шум частіше);
- нижче значення → реагує тільки на впевнену гучну мову.

Поріг і hangover (затримка вимкнення скролу після паузи в мовленні, зараз
650 мс) можна поміняти в `VoiceActivityDetector.kt`, якщо потрібно тонше
підлаштування під ваш голос/приміщення.

## Структура проекту

```
app/src/main/java/com/solod/teleprompter/
  MainActivity.kt              — екран редагування тексту й налаштувань
  PrompterActivity.kt          — повноекранний скрол-екран
  VoiceActivityDetector.kt     — VAD-логіка (AudioRecord + RMS)
app/src/main/res/layout/       — розмітка екранів
.github/workflows/build-apk.yml — CI-збірка APK на GitHub Actions
```
